About this page

We built this lab to train and fine-tune image-to-image and text-to-image models on a fixed train / validation / test split. This page shows what those runs saved: for each task, held-out images with the input, the model's output and the ground truth, and the run's own scores.

No model runs here. The trained checkpoints are 109-294 MB, over GitHub's 100 MB file limit, so they are not in the repository and this page cannot process an image you upload. Everything you see is a file committed under a project's samples/ folder.

Scores. The table at the top is the run's results.json. The number under each image is computed by this page from the saved PNG: RGB PSNR over the whole image against the ground truth, so it can differ from the run's own protocol.

"Earlier checkpoint" columns. The training scripts save their "before" images when a run starts or resumes. Where a run resumed, that column is a mid-run checkpoint of the same model, and it is labelled that way rather than as the starting weights.

Zoom. Turn on Zoom and click any image to compare the same small region of every column at full resolution; the super-resolution samples are 2K frames.
