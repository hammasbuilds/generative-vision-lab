# CUT - horse to zebra (contrastive, unpaired)

*A demonstration / portfolio project.*

## Notes

- NO scalar metric is reported. CUT is unpaired and has no cycle, so there is no held-out quantity to compare an output against. Inventing one would be worse than reporting none.
- 100 epochs. Its budget is matched to cyclegan-h2z so the two can be compared directly once that run finishes - same data, same schedule, different method. That pair is the point of this project.
